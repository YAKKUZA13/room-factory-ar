# TROUBLESHOOTING — ROOM FACTORY AR

## Камера

### «Камера недоступна», permission denied

- Нужен HTTPS или `localhost`. `http://192.168.x.x` с телефона — не secure context, камера обычно запрещена.
- Разрешение выдаётся только по user gesture: кнопка «Разрешить камеру», не автозапуск.
- iOS Safari: **Настройки → Safari → Камера** (или сайт → настройки). Android Chrome: иконка замка → Permissions → Camera.
- Если пользователь отказал раньше, браузер может помнить отказ; повторить после изменения настроек и перезагрузки.
- В private mode/ограниченном профиле камера может быть недоступна.

### Desktop показывает «AR недоступен на этом устройстве»

Это ожидаемо: world tracking 8th Wall рассчитан на мобильные устройства. Нажмите «Открыть 3D» — игра полностью доступна без камеры. Не используйте эмулятор веб-камеры как доказательство AR.

### Чёрный экран / камера не стартует

1. Проверьте, что другая вкладка/приложение не держит камеру.
2. Закройте вкладку и откройте URL заново (на некоторых iOS/Android повторный `XR8.run` нестабилен; приложение предлагает reload).
3. Проверьте, что `external/xr/xr.js` и `xr-slam.js` возвращают 200. На GitHub Pages project site URL должен быть `/repo/external/xr/...`, а не `/external/xr/...`.
4. Посмотрите diagnostics (`?debug=1`) и экспортируйте JSON (без кадров камеры).

## Маркер

### «Ищем карточку…» не переходит в «Привязка сохранена»

- Напечатано не 100%? Проверьте контрольные 100 мм линейкой; изображение должно быть 120 × 160 мм.
- Блики/ламинация/сламинат — используйте матовую бумагу.
- Слишком далеко/близко, размыто, мало света, маркер наклонён.
- Маркер должен быть тем же, что в `public/marker/room-factory-marker.json` (`name: room-factory-marker`).
- При SLAM LIMITED привязка намеренно запрещена; дождитесь NORMAL.
- Если маркер не распознаётся вообще: перегенерируйте официальным CLI (`npm run marker:generate`), проверьте, что в `dist/marker` попали все companion-файлы, и заново напечатайте.

### Завод «уехал» после перезапуска

- Если был temporary placement — это ожидаемо: anchor не перезаписывается. Нужно снова показать карточку или перепривязать.
- Если карточку физически переместили — виртуальный завод следует за ней; это ограничение marker-relative подхода, не «вечный якорь».
- Drift SLAM: посмотрите pose error в diagnostics; при большой ошибке приложение просит подтвердить восстановление.
- Не используйте сохранённую `T_W_F` из прошлой сессии: приложение это не делает.

## 8th Wall runtime / лицензия

- `@8thwall/engine-binary` — не MIT и не open-source SLAM. Не модифицируйте/reverse-engineer бинарник.
- Runtime должен публиковаться целиком, не только `xr.js`; скрипт копируется из `node_modules/@8thwall/engine-binary/dist`.
- Если `xr.js` 404: проверьте `VITE_BASE_PATH` и `dist/external/xr`. `verify-dist.mjs` ловит это.
- Если движок не загрузился за 20 с — экран ошибки, «Повторить»/«3D». Не бесконечный spinner.
- Лицензия разрешает бесплатное приложение без взимания платы; проверьте актуальные permitted uses перед коммерциализацией.

## GitHub Pages

### 404 на всей странице

- Pages Source должен быть **GitHub Actions**, не branch.
- Workflow должен задеплоить `dist`, не корень.
- Base path: project site `/<repo>/`; user site `<owner>.github.io` — `/`. Workflow определяет это по имени репозитория; можно переопределить `VITE_BASE_PATH`.
- Проверьте, что `index.html` ссылается на `/<repo>/assets/...`, а не `/assets/...`.

### Ассеты 200 локально, 404 на Pages

- Абсолютные `/src/...`, `/external/xr/...`, `/marker/...` ломаются под subpath. В проекте используются `BASE_URL`, `new URL`, runtime loader и `verify-dist`.
- Проверьте `dist/external/xr/xr-slam.js` (большой chunk) и `dist/marker/room-factory-marker_luminance.png`.
- MIME `text/javascript`/`application/json`/`image/png` должны быть корректны; GitHub Pages обычно ок.

### После обновления сайта старый завод не грузится

- Неизвестная версия схемы отклоняется осознанно. Экспортируйте/сохраните данные, не пытайтесь «угадать» миграцию.
- Проверьте ключ `room-factory-ar/save/v1` и `schemaVersion`.

## Сохранение / storage

### «localStorage недоступен»

- Private mode, политика браузера, очистка storage, квота. Игра работает, но прогресс не сохранится; используйте «Экспорт JSON».
- На iOS скачивание может открывать share sheet; используйте его или скопируйте файл.

### «Сохранение повреждено»

- Приложение не падает: показывает recovery screen. Можно экспортировать исходные данные и начать заново.
- Причина обычно — ручное редактирование localStorage, обрыв записи или старая несовместимая схема.
- Импорт проверяет размер (≤512 КБ), JSON, типы, границы, anchor name/version; код не исполняется.

### Autosave не срабатывает

- Autosave раз в 10 с при изменениях; при `hidden/pagehide` — синхронная попытка.
- Если вкладка была скрыта, offline income не начисляется; accumulator сбрасывается.
- Сохранение не создаётся просто от просмотра стартового экрана — нужен запуск игры/команда.

## Производительность

### Низкий FPS в AR

- Отключите тени/постобработку (в проекте их нет по умолчанию), уменьшите число зданий, закройте другие вкладки.
- DPR ограничен 1.5 для desktop viewer; в AR рендерер принадлежит 8th Wall, не форсируйте его настройки.
- Diagnostics: draw calls/triangles/FPS. Не сравнивайте mock/desktop FPS с AR FPS.

### Низкий FPS в 3D

- Settings → Performance: `low` (DPR 1), `auto`, `high`.
- Меньше зданий/меньше видимых предметов; закройте devtools.
- Не создавайте второй `WebGLRenderer`/второй RAF: режимы переключаются с dispose/reload.

## Переключение режимов

- AR → 3D: сохраняет и перезагружает страницу (избегает второго camera stream/дублирующихся XR modules). Это ожидаемо.
- 3D → AR: viewer освобождает WebGL, создаётся AR canvas; один engine продолжает работать.
- Если после возврата из Safari камера чёрная — закройте вкладку/перезагрузите; это ограничение браузера, приложение показывает recovery UI.

## Диагностика

- `?debug=1` — панель/меню диагностики.
- `?mockAR=1&debug=1` (в dev достаточно `?mockAR=1`) — **только** тестовый mock, badge `MOCK AR`; не доказательство AR.
- Экспорт diagnostics не содержит кадров камеры, скриншотов и геолокации; отправка только вручную.
